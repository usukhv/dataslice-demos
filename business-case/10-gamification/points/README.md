# Оноо, шагналын хүснэгт

- `rules.csv`: 5 үйлдэл ба оноо (`Дүрэм` таб).
- `log.csv`: Google Forms-оос ирэх хариулттай ижил бүтэцтэй 5 туршилтын мэдүүлэг (`Бүртгэл` таб).

Нээх: нэг хүснэгтэд `Дүрэм`, `Бүртгэл` табууд үүсгэж CSV бүрийг **File > Import > Upload**, **Replace current sheet**-ээр оруул. Жинхэнэ ажилд `Бүртгэл` табыг Forms өөрөө үүсгэнэ.

`Бүртгэл` табын **E1** нүдэнд (бүх мөрийг нэг томьёо хамарна):

```
={"Оноо"; ARRAYFORMULA(IF(C2:C="", "", XLOOKUP(C2:C, 'Дүрэм'!A:A, 'Дүрэм'!B:B, 0)))}
```

Pivot table (**Rows** = Ажилтан, **Values** = Оноо) хийхэд жишээ өгөгдлөөр: Ажилтан-1 15, Ажилтан-2 35, Ажилтан-3 5.

Түвшин (pivot-ын хажууд, B нь нийт оноо): `=IF(B2>=250, "Алт", IF(B2>=100, "Мөнгө", "Хүрэл"))`.

Солих зүйл: үйлдэл, оноо, ажилтны нэр. Forms-ын **Үйлдэл** dropdown-ий сонголтыг `Дүрэм` табтай яг ижил бич.
