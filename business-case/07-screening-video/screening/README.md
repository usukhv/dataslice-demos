# Нэр дэвшигч шүүх

- `candidates.csv`: нэргүй болгосон 5 туршилтын анкет, AI үнэлгээ ба видео онооны баганатай.
- `screening-prompt.txt`: шалгуураар үнэлүүлэх prompt.
- `messages.md`: видео хариултын 3 асуулт, урилгын мессеж.

Нээх: Google Sheets дээр **File > Import > Upload**, **Replace current sheet**, **Import data**.

**K2** нүдэнд видео онооны нийлбэр, доош нь чирж хуул:

```
=IF(COUNT(H2:J2)=3, SUM(H2:J2), "")
```

Нийт 12 ба түүнээс дээш бол ярилцлагад урь. Солих зүйл: шалгуур, салбарын нэр, асуултууд.
