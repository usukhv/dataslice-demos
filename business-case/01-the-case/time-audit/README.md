# Цаг иддэг ажлын жагсаалт

- `time-audit.csv`: 5 жишээ ажилтай хүснэгтийн загвар.

Нээх: sheets.google.com дээр **Blank spreadsheet** үүсгээд **File > Import > Upload** хийж файлаа чирж оруул. **Import location**-д **Replace current sheet** сонгоод **Import data** дар.

**E2** нүдэнд сард зарцуулах цагийг тооцоол, доош нь чирж хуул:

```
=C2*D2/60
```

Жишээ мөрүүдийг устгаад өөрийн 5 ажлаа бич. Хүлээгдэх үр дүн (жишээ өгөгдлөөр): 8, 4, 4, 5.5, 0.75 цаг.
