# Процессын зураглалын загвар

- `process-map.csv`: нийлүүлэгчийн төлбөрийн процессын 6 алхамтай жишээ.
- `ask-ai-prompt.txt`: зураглалаа AI чатад өгөх prompt.

Нээх: Google Sheets дээр **File > Import > Upload**, **Replace current sheet**, **Import data**.

Томьёо (2-р мөрөнд бичээд доош чирж хуул):

```
G2: =E2*F2/60
I2: =G2*H2
```

**View > Freeze > 1 row** хийгээд **I** баганын үсэг дээр баруун товшиж **Sort sheet Z to A** сонгоход хамгийн өвдөлттэй алхам дээр гарна. Жишээ өгөгдлөөр 6-р алхам (тулгалт) 24 оноотой тэргүүлнэ.

Солих зүйл: алхам, хүн, минутаа өөрийн процессоор бич.
