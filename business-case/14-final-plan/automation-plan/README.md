# Автоматжуулалтын төлөвлөгөө

- `plan-template.md`: 9 хэсэгтэй 1 хуудас төлөвлөгөөний загвар, жишээ бөглөлттэй.
- `review-prompt.txt`: төлөвлөгөөгөө AI-аар шүүмжлүүлэх prompt.
- `repeat-customers.md`: давтан ирэх харилцагчийн хувийг тооцох 3 томьёо.

Хэрэглэх: `plan-template.md`-г Google Docs-д `Автоматжуулалтын төлөвлөгөө` нэрээр хуулж, жишээ текстийг өөрийнхөөр соль. Ихэнх хэсгийг өмнөх хичээлийн даалгавраас (01, 02, 03, 13) хуулна.

Төлөвлөгөөг AI-д өгөхөөс өмнө нэр, утас, дансны дугаарыг хас.
