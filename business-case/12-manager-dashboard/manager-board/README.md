# Менежерийн самбар ба чатын сэдэв

- `tasks.csv`: `Ажил` табын загвар (Огноо, Хэн, Ажил, Зорилго, Төлөв), 5 жишээ.
- `chat-topics.csv`: AI-ийн ангилсан мессежийг хүснэгтэд буулгасан жишээ.
- `chat-topics-prompt.txt`: групп чатын мессежийг сэдвээр ангилуулах prompt.

Нээх: CSV бүрийг тусдаа табд **File > Import > Upload**, **Replace current sheet**-ээр оруул.

Долоо хоногийн шалгалт: `Ажил` таб дээр **Insert > Pivot table**, **Rows** = Зорилго, **Values** = Ажил (**COUNTA**). Жишээ өгөгдлөөр `Гэнэтийн асуудал` 2 удаа гарч тэргүүлнэ.

Сэдэв тоолох (`chat-topics` таб, D2-оос эхлэн сэдвийн нэр бичээд E2-д):

```
=COUNTIF(B:B, "*"&D2&"*")
```

Солих зүйл: зорилгоо (З1, З2, З3) өөрийнхөөр бич. Мессежээс нэр, утсыг хасахаа бүү март.
