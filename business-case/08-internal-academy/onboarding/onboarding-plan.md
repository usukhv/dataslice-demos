# Эхний 5 өдөр

1. Компанийн түүх, үнэт зүйл, үйлчилгээний зарчим
2. Касс, төлбөрийн төрөл, баримт олгох
3. Гол 10 бүтээгдэхүүн ба ялгаа
4. Харилцагчийг угтах, асуух, зөвлөх
5. Өдрийн нээлт, хаалтын журам

Сэдэв бүр: 3-5 минутын утсан бичлэг + 5 асуулттай Google Forms тест.

## Видео төлөвлөгөө бичүүлэх prompt

```
[Сэдэв 2: Касс] сэдвээр шинэ худалдааны зөвлөхөд зориулсан 4 минутын видеоны төлөвлөгөө гарга.
Эхэнд нь: энэ видеог үзээд юу хийж чаддаг болох вэ.
Дараа нь 4-5 хэсэг, хэсэг бүрт юу үзүүлж, юу хэлэх вэ.
Манай журам: [өөрийн журмаа товч бич].
```

## Тест гаргах prompt

```
Доорх видео скриптэд ЗӨВХӨН тулгуурлан 5 асуулт гарга.
Асуулт бүр 3 сонголттой, 1 зөв хариулттай. Зөв хариултыг тусад нь жагсаа.
Скриптэд байхгүй мэдээлэл бүү нэм.

[скрипт]
```
