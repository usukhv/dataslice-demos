# Onboarding ба карьерын шат

- `onboarding-tracker.csv`: ажилтан x сэдэв хүснэгт (тестийн %, дадлагын 8+ оноо авсан тоо).
- `career-ladder.csv`: 3 шаттай карьерын шат, шалгуур, сургалт.
- `onboarding-plan.md`: эхний 5 өдрийн сэдэв, видео төлөвлөгөө ба тест гаргах prompt.

Нээх: нэг хүснэгтэд 2 таб (`Явц`, `Шат`) үүсгэж CSV бүрийг **File > Import > Upload**, **Replace current sheet**-ээр оруул.

`Явц` табын **I2** нүдэнд, доош нь чирж хуул:

```
=IF(AND(COUNTIF(C2:G2, ">=80")=5, H2>=3), "Тийм", "Үгүй")
```

Жишээ өгөгдлөөр Ажилтан-1 Тийм, бусад нь Үгүй гарна. Солих зүйл: сэдвийн нэр, босго (80%, 3 удаа).
