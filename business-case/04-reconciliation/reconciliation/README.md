# Тулгалтын хүснэгт

- `statement.csv`: банкны хуулгын 8 зарлага (Огноо, Нийлүүлэгч, Дүн, Гүйлгээний утга).
- `receipts.csv`: 7 баримт (Огноо, Нийлүүлэгч, Дүн, Баримтын дугаар).

Нээх: шинэ хүснэгтэд 2 таб үүсгэж `Хуулга`, `Баримт` гэж нэрлэ. Таб бүр дээр **File > Import > Upload**, **Replace current sheet**, **Import data**.

`Хуулга` табын **E1**-д `Баримттай эсэх`, **E2**-д доорх томьёо, дараа нь доош чирж хуул:

```
=IF(COUNTIFS('Баримт'!B:B, B2, 'Баримт'!C:C, C2) > 0, "Тийм", "Үгүй")
```

Утга: `Баримт` табд ижил нийлүүлэгч (B), ижил дүнтэй (C) мөр дор хаяж 1 байвал Тийм, байхгүй бол Үгүй.

Жишээ өгөгдлийн хүлээгдэх үр дүн:
- Тэнгэр Принт 85000: Үгүй, баримт үнэхээр ирээгүй.
- Номин ХХК 210000: Үгүй, нэр зөрсөн (баримтад `Номин`).
- Эко Хүнс 300000: Үгүй, нэг төлбөрт 2 баримт (180000 + 120000).
- Цэвэр Ус 48000 (10-30): Тийм гэж гарна, гэхдээ баримт ганцхан. Ижил дүн давтагдвал томьёо нэг баримтыг 2 удаа тоолдог тул ийм мөрийг гараар шалга.

Банкны жинхэнэ хуулгыг AI чатад бүү хуул. Томьёо хүснэгт дотроо ажилладаг.
