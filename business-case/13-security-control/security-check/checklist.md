## 1. Мэдээлэл
- [ ] Хүснэгт, маягт бүрийн багана бүр юунд хэрэгтэйг шалгасан
- [ ] Регистрийн дугаар, төрсөн огноо, эрүүл мэндийн мэдээлэл хадгалдаггүй (эсвэл хассан)

## 2. 2-Step Verification
- [ ] Бизнесийн Google бүртгэл: myaccount.google.com > Security & sign-in > 2-Step Verification
- [ ] Имэйл, банк, Facebook хуудас, Instagram

## 3. Хуваалцах эрх (Share)
- [ ] Ажлаас гарсан хүн жагсаалтад байхгүй
- [ ] Anyone with the link үлдээгүй, Restricted
- [ ] Засах шаардлагагүй хүн Viewer эрхтэй

## 4. Backup
- [ ] Чухал хүснэгтүүдийг File > Download > Microsoft Excel (.xlsx) хийж өөр газар хадгалсан
- [ ] Сар бүрийн сануулга Google Calendar-т байгаа

## 5. AI чат

- [ ] AI хэрэгслийн нууцлалын тохиргоог шалгасан
