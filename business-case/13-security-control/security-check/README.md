# Аюулгүй байдлын 1 цагийн шалгалт

- `checklist.md`: 6 хэсэгтэй шалгах жагсаалт (мэдээлэл, 2-Step Verification, хуваалцах эрх, backup, AI, offboarding) ба мөнгөний 4 хяналт.
- `access-register.csv`: хэн юунд ямар эрхтэй вэ гэдгийг бүртгэх хүснэгт.

Хэрэглэх: `checklist.md`-г Google Docs-д хуулж, сар бүр нэг удаа дагаж шалга. `access-register.csv`-г **File > Import > Upload**-оор Google Sheets-д оруулж, ажилтан орох, гарах бүрт шинэчил.

Солих зүйл: жишээ мөрүүдийг өөрийн хэрэгсэл, хүмүүсээр соль. Энэ хүснэгтэд нууц үг хэзээ ч бүү бич.
