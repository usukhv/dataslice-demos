# Сарын тайлан

- `sales.csv`: 2026 оны 10, 11-р сарын 12 борлуулалтын мөр (Сар, Огноо, Салбар, Ажилтан, Бүтээгдэхүүн, Дүн).
- `report-prompt.md`: pivot table-ийн хураангуйгаас тайлбарын ноорог бичүүлэх prompt.

Нээх: Google Sheets дээр **File > Import > Upload**, **Replace current sheet**, **Import data**. Дараа нь **Insert > Pivot table**: **Rows** = Салбар, **Columns** = Сар, **Values** = Дүн (SUM).

Хүлээгдэх pivot (төгрөг):

```
Салбар   10-р сар   11-р сар   Өсөлт
Зүүн     1200000    1500000    +25%
Төв      2000000    2300000    +15%
Хойд     1500000    1200000    -20%
Нийт     4700000    5000000
```

Өсөлтийн томьёо (pivot-ын хажууд): `=(C3-B3)/B3`, **Format > Number > Percent**.

Солих зүйл: өөрийн борлуулалтын хүснэгтээ ижил баганатайгаар оруул.
