# Сарын тайлангийн prompt

Pivot table-ийн хураангуйг (хувийн мэдээлэлгүй) доорх `[ ]` хэсэгт хуулж тавь.

```
Чи манай жижиг компанийн санхүүгийн туслах.
Доорх нь [10-р] ба [11-р] сарын салбар тус бүрийн борлуулалт (төгрөгөөр):

[pivot table-ээсээ хуулж тавь]

Даалгавар:
1. Тоог өөрчлөхгүйгээр салбар бүрийн өсөлт, бууралтыг хувиар тооцоол. Тооцооллоо харуул.
2. Түншүүдэд зориулсан 5-7 өгүүлбэрийн товч тайлбар бич. Энгийн, албан ёсны өнгөөр.
3. Тоо юуг тайлбарлаж ЧАДАХГҮЙ байгааг тусад нь бич: надаас асуух асуултаа жагсаа.
Таамаг бүү гарга. Мэдэхгүй зүйлээ "тодорхойгүй" гэж бич.
```

Сар бүр хэрэглэх бол энэ файлыг Google Docs-д `Сарын тайлангийн prompt` нэрээр хадгал. Эцсийн хувилбар болсон нэг сарын тайлангаа prompt-ын доор жишээ болгон нэмбэл AI тэр хэв маягийг дагана.
