# Ажлын анкет

- `form-questions.md`: Google Forms-д оруулах 7 асуулт, төрөл бүрээр, зөвшөөрлийн тексттэй.
- `job-ad-prompt.txt`: Facebook, Instagram-д тавих зар бичүүлэх prompt.

Google Forms файл импортлодоггүй тул асуултыг forms.google.com дээр **Blank form** үүсгээд нэг нэгээр хуулж тавина (10 минут орчим).

Солих зүйл: ажлын байрны нэр, салбарын нэрс, устгах хугацаа (6 сар). Хариултыг **Responses > Link to Sheets** хийж хүснэгт рүү холбо.
