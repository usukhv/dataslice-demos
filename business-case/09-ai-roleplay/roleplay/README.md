# AI-тай дүрд тоглох дадлага

- `roleplay-prompts.md`: 3 харилцагчийн дүр (үнэд эргэлзэгч, яаруу, гомдолтой), 10 онооны үнэлгээтэй.
- `practice-log.csv`: дадлагын оноо бүртгэх хүснэгт.

Хэрэглэх: нэг дүрийн код блокийг бүхлээр нь хуулж ChatGPT, Gemini эсвэл Claude-ийн шинэ чатад тавь. Ярилцаад `ДУУСЛАА` гэж бичихэд үнэлгээ гарна.

Солих зүйл: `[ ]` доторх бизнесийн төрөл, бүтээгдэхүүн. Эрүүл мэндийн бүтээгдэхүүн бол эмчилгээний амлалтгүй шалгуурыг заавал үлдээ.

Дадлагын хүснэгтийг **File > Import > Upload**-оор оруулж, ахицыг харахад ажилтан тус бүрийн дунджийг `=AVERAGEIF(B:B, "Ажилтан-1", D:D)` томьёогоор ол.
