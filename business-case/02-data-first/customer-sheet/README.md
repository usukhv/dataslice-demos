# Харилцагчийн хүснэгтийн загвар

- `customers.csv`: 10 баганатай харилцагч, борлуулалтын хүснэгт, 5 жишээ мөр.

Нээх: sheets.google.com дээр **Blank spreadsheet** үүсгэж нэрийг `Харилцагч` болго. **File > Import > Upload** хийж файлаа оруул, **Replace current sheet**, **Import data**.

Дараа нь: **View > Freeze > 1 row**, **Салбар** ба **Сурталчилгаа авах зөвшөөрөл** баганад **Insert > Dropdown**.

Солих зүйл: салбар, ажилтны нэрийг өөрийнхөөр соль. Утас бүтэн хэрэггүй бол бүү хадгал (жишээнд `9911****` гэж нуусан). Жишээ мөрүүдийг устгаад өөрийн өгөгдлөө оруул.
