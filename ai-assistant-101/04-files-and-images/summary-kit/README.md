# Файл товчлох дадлагын багц

- `sample-report.txt`: зохиомол талх нарийн боовны компанийн сарын тайлан, тоо, огноотой. Нууц мэдээлэлгүй тул дадлагад чөлөөтэй ашиглана.
- `prompts.md`: товчлол, асуулт, зургаас хүснэгт гаргах 3 prompt.
- Ашиглах: AI туслахын чатын **+** товчоор `sample-report.txt`-г оруулаад `prompts.md`-ийн эхний prompt-ыг илгээ.
- Шалгах: товчлол дахь тоо бүрийг `sample-report.txt`-ээс хайж ол. Жишээ нь хүргэлтийн дундаж хугацаа 52 минут.
- Дараа нь өөрийн нууц мэдээлэлгүй PDF-ээр солиод давт.
