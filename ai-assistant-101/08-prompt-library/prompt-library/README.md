# Prompt сангийн загвар

- `prompt-library.md`: 5 prompt-ын сан. 1-р prompt бүрэн жишээ, 2–5 нь бөглөх хоосон загвар.
- Нээх: текст засварлагчаар нээгээд бүх текстийг хуулж, Google Docs-ийн шинэ баримтад буулга.
- Docs-д prompt бүрийн `## ...` гарчгийг **Heading 2** болгож, `##` тэмдгийг устга.
- [ ] доторх хэсгийг өөрийн ажлаар соль. Ажлын нэрийг 1-р хичээлийн жагсаалтаасаа ав.
- Prompt бүрийг 2 бодит жишээн дээр туршаад **Туршилт** мөрөнд тэмдэглэ.
- Жинхэнэ нэр, утас, нууц үг санд хэзээ ч бүү бич.
