# Нэргүй болгох дадлагын багц

- `sample-complaint.txt`: зохиомол харилцагчийн гомдол. Нэр, утас, хаяг, картын дугаар бүгд зохиомол.
- `checklist.md`: AI-д бичвэр оруулахаас өмнөх шалгах хуудас.
- Ашиглах: эхлээд гомдлыг AI-гүйгээр, гараар `checklist.md`-ийн дагуу нэргүй болго. Картын мөрийг бүхэлд нь хас.
- Дараа нь нэргүй болгосон хувилбараа AI-д өгч, харилцагчид хариу бичүүл.
- Жинхэнэ харилцагчийн бичвэрт ч яг ижил дарааллаар ажилла.
