# AI-д оруулахаас өмнөх шалгах хуудас

## Хэзээ ч бүү оруул
- [ ] Нууц үг, PIN, нэг удаагийн код
- [ ] Картын дугаар, интернэт банкны нэвтрэх мэдээлэл
- [ ] Регистрийн дугаар, иргэний үнэмлэх, паспорт
- [ ] Эрүүл мэндийн мэдээлэл
- [ ] API key, нууц гэрээ, санхүүгийн нууц тайлан

## Нэргүй болго
- [ ] Хүний нэр: `Харилцагч А`, `Ажилтан Б`
- [ ] Утас: `9911****`
- [ ] Хаяг: `Баянзүрх дүүрэг` хүртэл товчил
- [ ] Компани: `Манай компани`, `Нийлүүлэгч Б`
- [ ] Хэрэггүй дүнг хас эсвэл дугуйл

## Тохиргоо
- [ ] Сургалтын тохиргоог шалгасан (ChatGPT: Data controls, Claude: Privacy, Gemini: Keep Activity)
- [ ] Эмзэг сэдвээр түр чат ашигласан
