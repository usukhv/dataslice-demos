# Баримт шалгах хүснэгт

- `fact-check.csv`: AI-ийн хариунаас ялгасан 5 баримтыг бүртгэх загвар. Төрөл бүрт нэг мөр бэлэн.
- Нээх: Google Sheets-д **File > Import > Upload**, **Create new spreadsheet**, **Import data**.
- **Баримт** баганад AI-ийн хариунаас шалгах өгүүлбэрээ хуул.
- **Дүгнэлт** баганад `Зөв`, `Буруу`, `Шалгаж чадсангүй` гэсэн 3 утгын аль нэгийг бич.
- Эцэст нь хэд нь зөв байсныг тоолж, хичээлийн даалгаврын хариу болго.
