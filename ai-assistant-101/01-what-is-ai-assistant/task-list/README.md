# AI-д өгөх 5 ажлын жагсаалт

- `ai-tasks.csv`: 5 ажлын хүснэгтийн загвар. Эхний 2 мөр жишээ, үлдсэн 3 мөр хоосон.
- Нээх: Google Sheets-д **File > Import > Upload**, **Import location**-д **Create new spreadsheet** сонгоод **Import data**.
- Жишээ 2 мөрийг өөрийн ажлаар соль, 5 мөр болго.
- **Нууц мэдээлэлтэй юу** баганад `Тийм` гэсэн ажлыг 7-р хичээлээс өмнө AI-д бүү өг.
- Жагсаалтаа хадгал: 8-р хичээлд prompt сангийн үндэс болно.
