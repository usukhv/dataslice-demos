# component-kit

8-р хичээлийн Component болгох Feed загвар.

- `feed-template.svg`: 1080 × 1350. Давхаргууд нэртэй: `bg`, `photo`, `text-block` (`title`, `subtitle`, `cta`), `logo`.
- `styles.txt`: 4 Text style, 5 Color variable, Auto layout-ийн тохиргоо.

1. SVG-г **Загварууд** хуудас руу чирж оруул.
2. `styles.txt`-ийн дагуу Style, Variable үүсгээд давхарга бүрт хэрэглэ.
3. `cta`, `text-block`-ийг сонгоод **Shift + A** дарж Auto layout болго.
4. Frame-ийг сонгоод **Create component** дар.
SVG-д Auto layout, Component хадгалагддаггүй тул эдгээрийг Figma дотор өөрөө хийнэ.
