# cyrillic-fonts

6-р хичээлийн фонтын жагсаалт ба тест карт.

- `fonts.txt`: Ө, Ү-тэй 22 Google фонт, Ө Ү-гүй фонтууд, 5 хослол, тест мөр.
- `font-test.svg`: 1080 × 1350. 3 хослолын карт (Inter, Lora + Golos Text, Oswald + Inter).

Нээх: `font-test.svg`-г **Brand kit** хуудас руу чирж оруул. Figma-д Google Fonts бэлэн байдаг тул фонт суулгах хэрэггүй.
Шалгах: Ө, Ү бусад үсгээс өөр хэлбэртэй харагдвал текстийг сонгоод фонтыг баруун самбараас дахин сонго.
Солих: текстийг өөрийн брэндийн гарчгаар, фонтыг `fonts.txt`-ийн жагсаалтаас соль.
