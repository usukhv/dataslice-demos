# image-prompts

13-р хичээлийн зургийн prompt ба шалгах жагсаалт.

- `image-prompt.md`: 6 хэсэгтэй prompt-ын загвар, 3 жишээ (Feed дэвсгэр, Story бүтэц, Carousel чимэглэл).
- `ai-image-checklist.md`: AI зураг нийтлэхээс өмнө шалгах 7 асуулт.

Ашиглах: `[ ]` хэсгийг өөрийн объект, брэндийн HEX-ээр соль. Prompt-ыг дурын AI зураг үүсгэгч эсвэл Figma-гийн **Make an image**-д хуулж тавь.
Зурагт текст бичүүлэхгүй. Гарчгийг Figma-д нэм.
