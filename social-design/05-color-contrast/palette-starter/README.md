# palette-starter

5-р хичээлийн 5 өнгөтэй жишээ палитр.

- `palette.svg`: 1080 × 1350. 5 өнгөний дугуй, HEX код, 4 контрастын карт (харьцаа нь бичигдсэн).
- `colors.txt`: өнгөний нэр, HEX, WCAG-ийн контрастын тооцоо. Харьцааг Python-оор WCAG томьёогоор бодсон.

Нээх: `palette.svg`-г **Brand kit** хуудас руу чирж оруул.
Солих: дугуй бүрийн **Fill**-ийг өөрийн өнгөөр соль. Дараа нь шинэ HEX-ээ
[WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)-ээр дахин шалгаж, картын харьцааг шинэчил.
Анхаар: цайвар текст / үндсэн өнгө (4.44:1) зориуд 4.5:1-д хүрэхгүй жишээ.
