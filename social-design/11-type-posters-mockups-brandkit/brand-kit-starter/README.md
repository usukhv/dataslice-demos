# brand-kit-starter

11-р хичээлийн brand kit-ийн эхлэл (зохиомол Сансар кофе).

- `brand-kit.svg`: 1920 × 2160 самбар. Лого, 5 өнгө, Text style, Component (CTA, үнийн шошго, слайдын дугаар), зураг, дуу хоолой, хориотой зүйлс.
- `quote-poster.svg`: 1080 × 1350 ишлэлийн постер, нэг онцлох үгтэй.
- `phone-mockup.svg`: 1080 × 1350 утасны энгийн mockup. `screen`-ийн **Fill**-д Story PNG-ээ чирж тавь.
- `colors.txt`, `fonts.txt`, `voice.md`: өнгө, фонт, дуу хоолойн загвар.

Нээх: SVG-үүдийг **Brand kit** хуудас руу чирж оруул. Сүүдрийг Figma-д **Effects** > **Drop shadow**-оор нэм.
Солих: Сансар кофе, лого, өнгө, текстийг бүгдийг өөрийн брэндээр соль.
