# post-starter

2-р хичээлийн `Post 01` пост, 1080 × 1350 хэмжээтэй SVG.

1. `post-01.svg` файлыг Figma-гийн **Дасгал** хуудас руу чирж оруул. Figma SVG-г засах боломжтой vector давхарга болгоно.
2. Дугуйг (`photo`) сонгоод өөрийн зургийн файлыг баруун самбарын **Fill** өнгөн дөрвөлжин дээр чирж тавь. `photo-label` текстийг устга.
3. Гарчиг, дэд мөрийг давхар дарж өөрийн текстээр соль. Текст vector болж орсон бол устгаад **T**-ээр дахин бич (Inter Bold 80, Inter Regular 36).
4. Дэвсгэрийн өнгө `#F7F1E8`, текстийн өнгө `#1F1A17`. Брэндийнхээ өнгөөр соль.
