# content-calendar

15-р хичээлийн календарь, Insights-ийн хүснэгт.

- `calendar-2weeks.csv`: 2026-11-16-ээс 14 өдөр, долоо хоногт 3 пост + өдөр бүр Story. Багана: огноо, гараг, формат, pillar, hook, CTA, төлөв.
- `insights-tracker.csv`: пост бүрийн views, reach, saves, shares, follows. Сүүлийн 2 багана Saves ÷ Reach, Shares ÷ Reach томьёо. Тоо нь жишээ, өөрийн Insights-ийн тоогоор соль.
- `final-checklist.md`: төгсгөлийн төслийн 7 зүйл ба шалгах жагсаалт.

Нээх: Google Sheets-д **File** > **Import** > **Upload**, CSV-ээ сонгоод **Import data** дар. Томьёо автоматаар ажиллана.
Сүүлийн 2 баганыг **Format** > **Number** > **Percent** болго.
Огноо, hook-ийг өөрийн бизнесээр соль.
