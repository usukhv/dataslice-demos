# format-templates

7-р хичээлийн 4 форматын загвар, жинхэнэ px хэмжээтэй SVG.

- `feed-1080x1350.svg`: Feed 4:5. `guides` нь 80 px margin, `grid-crop-3x4` нь профайлын торонд тайрагдах 34 px зурвас.
- `square-1080x1080.svg`: квадрат 1:1, 80 px margin.
- `story-1080x1920.svg`: `safe-zone` group: дээд 270, доод 672, хажуу 65 px (Meta: 14% / 35% / 6%).
- `reel-cover-1080x1920.svg`: safe zone + `crop-3x4` (дээд, доод 240 px). Гарчгаа Y 270-1248 хооронд тавь.

Нээх: файлуудыг **Загварууд** хуудас руу чирж оруул. Тус бүр зөв хэмжээтэй Frame болж орно.
Солих: `photo` тэгш өнцөгтийн **Fill**-д зургаа чирж тавь, текстийг соль.
Экспортын өмнө `guides`, `safe-zone`, `crop-3x4`, `grid-crop-3x4` давхаргыг нүдээр нь нуу.
