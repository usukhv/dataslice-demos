# policy-qa

Prompt engineering, 7-р хичээл: зохиомол мэдээллээс сэргийлэх.

- `before.txt`: журам ба асуултыг дүрэмгүй асуусан prompt.
- `after.txt`: мэдэхгүй гэх эрх, эхлээд `<quotes>` ишлэл, дараа нь `<answer>` гэсэн 2 алхамтай prompt.

Зөв хариу: 1-р асуулт болохгүй (5-р заалт), 2-р асуулт болохгүй (2-р заалт), 3-р асуулт журамд заагаагүй.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш.
Өөрийнхөөрөө солих: журмын оронд өөрийн баримтыг тавь. Нууц, хувийн мэдээллийг хас. Журам, компани бүгд зохиомол.
