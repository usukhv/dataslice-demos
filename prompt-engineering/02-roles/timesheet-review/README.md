# timesheet-review

Prompt engineering, 2-р хичээл: үүрэггүй ба үүрэгтэй prompt.

- `before.txt`: цагийн бүртгэлийг үүрэггүйгээр шалгуулах prompt.
- `after.txt`: хүний нөөцийн мэргэжилтний үүрэг, уншигч (захирал) нэмсэн prompt.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш.
Өөрийнхөөрөө солих: үүргийг өөрийн салбар, туршлагаар, хүснэгтийг өөрийн өгөгдлөөр соль. Ажилтны жинхэнэ нэрийг бүү ашигла.
