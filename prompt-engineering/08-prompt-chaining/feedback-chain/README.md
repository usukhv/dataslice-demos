# feedback-chain

Prompt engineering, 8-р хичээл: том ажлыг prompt chain болгох.

- `before.txt`: бүх ажлыг нэг prompt-д шахсан хувилбар.
- `step1-classify.txt` ... `step4-check.txt`: 4 алхамтай chain. Алхам бүрийн гаралтын tag-ийг (`<classified>`, `<issues>`, `<report>`) дараагийн файлын `...` хэсэгт буулгана.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш.
Өөрийнхөөрөө солих: санал асуулга, хурлын тэмдэглэл, гомдол зэрэг өөрийн өгөгдлөөр соль, алхмын тоог 3–4 байлга.
