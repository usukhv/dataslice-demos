# application-template

Prompt engineering, 3-р хичээл: заавар ба өгөгдлийг XML tag-аар салгах.

- `before.txt`: заавар ба өргөдөл холилдсон prompt.
- `after.txt`: өргөдөл `<application>` tag дотор орсон prompt.
- `template.txt`: `{{ӨРГӨДӨЛ}}`-ийн оронд шинэ өргөдөл тавьж дахин ашиглах загвар.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш.
Өөрийнхөөрөө солих: баримтын төрөл, tag-ийн нэр, товчлолын дүрмийг өөрийн ажилд тааруул. Иргэний жинхэнэ утас, нэрийг хас.
