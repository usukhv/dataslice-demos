# Prompt шалгах хуудас

Асуулт бүрт тийм эсвэл үгүй гэж хариул.

1. Шинэ ажилтан энэ prompt-ыг уншаад нэмэлт асуултгүйгээр ажлаа хийж чадах уу?
2. Даалгавар, нөхцөл, өгөгдөл, хэлбэр гэсэн 4 хэсэг бүгд байгаа юу?
3. Үүрэг ба уншигчийг тодорхой заасан уу?
4. Чухал дүрэм бүр шалтгаантай юу?
5. Өгөгдөл заавраас XML tag-аар тусгаарлагдсан уу?
6. Хариуны урт, бүтцийг тоогоор заасан уу?
7. Жишээнүүд олон янз, мэдээлэл дутуу тохиолдлыг хамарсан уу?
8. Мэдээлэл дутуу үед юу хариулахыг заасан уу?
9. Олон нөхцөлтэй ажилд бодлоо хариунаас өмнө бичүүлсэн үү?
10. 5 тестийг сүүлийн хувилбараар бүгдийг нь дахин ажиллуулсан уу?
