# prompt-project

Prompt engineering курсын төгсгөлийн төслийн загвар файлууд.

- `template.txt`: сайжруулсан prompt-ын загвар. `{{...}}` хэсгүүдийг өөрийн ажлаар соль, хэрэггүй хэсгийг устга.
- `test-log.md`: 5 тест оролт, амжилтын шалгуур, өмнөх ба сайжруулсан хувилбарын оноог бичих хуудас.
- `checklist.md`: prompt-оо шалгах 10 асуулт.

Файлуудыг ямар ч текст засварлагчаар нээнэ. Prompt бүрийг Claude.ai-д шинэ чатад хуулж ажиллуул.
Бодит өгөгдөл ашиглахдаа нэр, утас, регистрийн дугаар зэрэг хувийн мэдээллийг хас.
