# product-cards

Prompt engineering, 6-р хичээл: жишээгээр заах (few-shot).

- `before.txt`: жишээгүй prompt.
- `after.txt`: 3 олон янзын жишээтэй prompt.
- `edge-example.txt`: мэдээлэл дутуу үеийн жишээ. `after.txt`-ийн `<examples>` дотор нэмж турш.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш. Хувилбар бүрийг 3 удаа ажиллуулж бүтэц тогтвортой эсэхийг хар.
Өөрийнхөөрөө солих: бүтээгдэхүүний оронд өөрийн давтагддаг хөрвүүлэлтийн 3 жишээг бич.
