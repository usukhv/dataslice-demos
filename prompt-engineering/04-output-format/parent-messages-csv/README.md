# parent-messages-csv

Prompt engineering, 4-р хичээл: хариуны хэлбэрийг заах.

- `before.txt`: хэлбэр заагаагүй prompt.
- `after.txt`: багана, зөвшөөрөгдөх утга, CSV хэлбэрийг заасан prompt. Хариуг Google Sheets-ийн A1 нүдэнд буулгаад **Data** цэсээс **Split text to columns** дар.
- `reply-skeleton.txt`: хариуг `<summary>`, `<action>`, `<reply>` tag-д хуваах араг.

Файлуудыг текст засварлагчаар нээгээд агуулгыг нь Claude.ai-д шинэ чатад хуулж илгээ. Хувилбар бүрийг тусдаа шинэ чатад турш.
Өөрийнхөөрөө солих: баганын нэр, төрлийн жагсаалт, мессежүүдийг өөрийн өгөгдлөөр соль.
