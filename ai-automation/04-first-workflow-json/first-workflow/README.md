# Анхны workflow: захиалгын дүн

- `workflow.json`: **Manual Trigger**, `Захиалга`, `Нийт дүн` гэсэн 3 node. Credential шаардахгүй.
- Import: шинэ workflow нээгээд баруун дээд буланд байрлах **...** цэснээс **Import**, дараа нь **From file** сонгоод файлаа сонго.
- Эсвэл файлын агуулгыг бүтнээр нь хуулж canvas дээр `Ctrl` + `V` (Mac: `Cmd` + `V`) дар.
- **Execute workflow** дар. `Нийт дүн` node-ийн output-д `total: 170000` гарна.
- `Захиалга` node-ийн үнэ, тоо ширхгийг өөрийн бараагаар солиод дахин ажиллуул.
