# Автоматжуулах ажлын жагсаалт

- `automation-ideas.csv`: ажил бүрийг trigger, action, AI алхам болгон задалсан хүснэгтийн загвар. Эхний 4 мөр нь жишээ.
- Google Sheets-д нээх: **File** цэснээс **Import** сонгоод **Upload** табаас файлаа оруул.
- Жишээ мөрүүдийг устгаад өөрийн 3 ажлаа бич.
- `ai_алхам` баганыг AI хэрэггүй бол хоосон үлдээ.
- `долоо_хоногт_хэмнэх_цаг` хамгийн өндөр мөрөө курсийн турш ашиглана.
