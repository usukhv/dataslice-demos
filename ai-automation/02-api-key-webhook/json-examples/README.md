# JSON жишээнүүд

- `order.json`: энгийн захиалга. Key, value, жагсаалт (`[ ]`) ямар харагддагийг хар.
- `telegram-update.json`: Telegram-аас n8n-д ирдэг мессежийн бүтэц. Нэрс, дугаар нь зохиомол.
- `gemini-response.json`: n8n-ийн **Google Gemini** node-ийн output-тэй ижил бүтэцтэй хариу.
- Файлыг текст editor эсвэл хөтчөөр нээ (Firefox, Chrome JSON-ийг модлог байдлаар харуулна).
- Даалгавар: мессежийн текст, chat ID, Gemini-ийн хариу текст хүрэх замыг цэгээр холбож бич.
