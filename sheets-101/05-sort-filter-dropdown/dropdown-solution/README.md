# 5-р хичээлийн шийдэл

- `sales-05.xlsx`: 4-р хичээлийн шийдэл дээр Ангилал (C2:C21) ба Ажилтан (F2:F21) баганын dropdown нэмэгдсэн.
- Нээх: Google Sheets-ийн нүүрнээс шинэ хүснэгт нээгээд **File > Import > Upload**, файлаа сонгож **Import location**-д **Create new spreadsheet**, **Import data**. Өмнөх хүснэгт хөндөгдөхгүй.
- Excel-ийн жагсаалтын дүрэм Sheets-д dropdown болж орно. Харагдац нь өөр байвал C2:C21-ийг сонгоод **Data > Data validation**-оос шалга.
- C5-д `Кофе` гэж бичиж, dropdown буруу утгыг хэрхэн хүлээж авахгүйг туршина.
