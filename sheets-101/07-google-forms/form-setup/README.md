# Google Forms тохиргооны жагсаалт

- `form-questions.md`: `Гүйлгээ бүртгэх` маягтын 5 асуулт, төрөл, сонголт, Required, Response validation.
- Google Forms-ыг файлаар импортлох боломжгүй тул маягтаа энэ жагсаалтыг дагаж гараар үүсгэ.
- Нээх: текст засварлагчаар нээгээд, хажуудаа маягтаа нээж мөр мөрөөр нь дага.
- Ангиллыг өөрийн бизнесийнхээр сольж болно. Сольсон бол 8-р хичээлийн `Тайлан` sheet-д яг ижил бич.
