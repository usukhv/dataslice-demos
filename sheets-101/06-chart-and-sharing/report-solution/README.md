# 6-р хичээлийн шийдэл

- `sales-06.xlsx`: `Тайлан` sheet-ийн A8:B11-д SUMIF хураангуй, B12-д шалгах нийлбэр, ангиллын багана график.
- Нээх: Google Sheets-ийн нүүрнээс шинэ хүснэгт нээгээд **File > Import > Upload**, файлаа сонгож **Import location**-д **Create new spreadsheet**, **Import data**. Өмнөх хүснэгт хөндөгдөхгүй.
- Excel-ийн график Sheets-д орохдоо хэлбэрээ бага зэрэг өөрчилж болно. Тэгвэл графикийг устгаад **Insert > Chart**-аар дахин үүсгэ.
- Хүлээгдэх хариу: Талх 404500, Бялуу 571000, Ундаа 388500, нийт 1364000.
- Хуваалцах эрхийг файлд хадгалах боломжгүй тул **Share**-ийг өөрөө тохируул.
