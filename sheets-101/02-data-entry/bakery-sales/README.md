# Талх нарийн боовны борлуулалт: жишээ өгөгдөл

- `sales.csv`: 7 хоногийн 20 борлуулалт. Багана: Огноо, Бараа, Ангилал, Тоо, Үнэ, Ажилтан.
- Нэг мөр = нэг борлуулалт. Тоо, үнэ зөвхөн цифрээр, огноо `ЖЖЖЖ-СС-ӨӨ` хэлбэрээр.

Оруулах:

1. Google Sheets-д `Борлуулалт 2026` хүснэгтээ нээ.
2. **File > Import** дараад **Upload** хэсэгт `sales.csv`-г сонго.
3. **Import location**-д **Replace current sheet**-ийг сонгоод **Import data** дар.

Өөрийн өгөгдлөөр солих бол багануудыг хэвээр үлдээж, мөрүүдийг л соль. Курсийн 3–6-р хичээл энэ өгөгдлийг ашиглана.
