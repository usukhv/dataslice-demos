# Борлуулалтын хүснэгтийн загвар

- `sales-template.csv`: 6 гарчиг ба 1 жишээ мөр: Огноо, Бараа, Ангилал, Тоо, Үнэ, Ажилтан.
- Оруулах: `Борлуулалт 2026` файлын `Борлуулалт` sheet-ийг нээгээд **File > Import > Upload**, **Replace current sheet**, **Import data**.
- Гарчгийг өөрчлөхгүй байх нь дараагийн хичээлүүдэд амар. Жишээ мөрийг өөрийн борлуулалтаар соль.
- 2-р хичээлд энэ sheet-ийг 20 мөртэй жишээ өгөгдлөөр солино.
