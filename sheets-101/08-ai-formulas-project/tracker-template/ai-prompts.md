# AI-аас томьёо асуух prompt-ууд

## Ангиллын тайлан
```text
Би Google Sheets ашиглаж байна.
"[хариултын sheet-ийн нэр]" sheet-ийн баганууд:
A цаг, B Огноо, C Төрөл (Орлого эсвэл Зардал),
D Ангилал, E Дүн (тоо), F Тайлбар. Гарчиг 1-р мөрөнд.
"Тайлан" sheet-ийн A2:A6-д ангиллын нэрс байна.
B2-д тухайн ангиллын нийт орлого, C2-д нийт зардлыг
гаргах томьёо бич. B2:C6 руу хуулахад зөв ажиллахаар $ ашигла.
Маягтын шинэ хариулт нэмэгдэхэд томьёо засварлах шаардлагагүй байг.
Томьёо бүрийг 2 өгүүлбэрээр тайлбарла.
```

## Сарын тайлан
```text
"Тайлан" sheet-ийн F1-д он сар (жишээ нь 2026-11-01) байна.
F2-д тэр сарын нийт орлого, F3-д нийт зардал, F4-д ашгийг
(орлого хасах зардал) гаргах томьёо бич. Огноо B баганад.
```

## Алдаа засуулах
```text
Энэ томьёо [алдааны мессеж] гэж байна:
[томьёо]
Миний баганууд: [баганын жагсаалт]. Яагаад ингэж байна, зас.
```
