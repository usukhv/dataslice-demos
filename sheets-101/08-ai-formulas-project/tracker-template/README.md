# Орлого, зардлын бүртгэлийн жишээ

- `tracker.xlsx`: `Хариултууд` sheet-д маягтын хариулттай ижил бүтэцтэй 12 зохиомол гүйлгээ, `Тайлан` sheet-д ангилал (SUMIFS), сарын орлого, зардал, ашиг ба график.
- `ai-prompts.md`: ангиллын тайлан, сарын тайлан, алдаа засуулах 3 prompt.
- Нээх: Google Sheets-ийн нүүрнээс шинэ хүснэгт нээгээд **File > Import > Upload**, файлаа сонгож **Import location**-д **Create new spreadsheet**, **Import data**. Өмнөх хүснэгт хөндөгдөхгүй.
- Өөрийн AI-аар бичүүлсэн томьёог энэ жишээтэй харьцуул. Томьёо өөр байж болно, хариу ижил байх ёстой.
- Хүлээгдэх хариу: нийт орлого 2315000, нийт зардал 2175000, 11-р сарын ашиг 140000.
- Өөрийн хүснэгтэд хуулахдаа `'Хариултууд'`-ыг өөрийн хариултын sheet-ийн нэрээр соль.
