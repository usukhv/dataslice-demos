# Захиалгын форм (10-р хичээл)

- `index.html`: `#booking` хэсэгт 7 талбартай форм. Талбар бүр `<label>`-тай, алдааны мессежийн газартай.
- `script.js`: `validateBooking()` шалгалт, монгол алдааны мессеж, **Илгээж байна...** төлөв. Өгөгдлийг Console-д хэвлэнэ.
- `styles.css`, `privacy.html`: загвар ба хувийн мэдээллийн бодлогын жишээ.

Нээх: `index.html` дээр давхар дар. Хоосон илгээж, утсанд үсэг бичиж турш.
Сервер рүү одоохондоо юу ч илгээхгүй. Үүнийг 11-р хичээлд нэмнэ.
Солих: `<select id="service">` дахь үйлчилгээ, үнэ, `script.js`-ийн `SLOTS` цагийн жагсаалт.
