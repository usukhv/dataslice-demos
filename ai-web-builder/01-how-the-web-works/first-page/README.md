# Анхны хуудас

- `index.html`: хуудасны бүтэц (гарчиг, текст, товч).
- `styles.css`: товчны өнгө, зай.

Нээх: zip-ийг задлаад `index.html` дээр давхар дар. Browser-т нээгдэнэ.
Солих: `Цэцэг салон` болон тайлбарын мөрийг өөрийн бизнесээр соль, `#2457e0`-ийг өөр өнгөөр сольж үз.
Хадгалаад browser-оо refresh хий (**Cmd/Ctrl + R**).
