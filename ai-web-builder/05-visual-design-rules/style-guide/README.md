# Style guide

- `style-guide.svg` (1440 x 900): өнгө (hex ба contrast харьцаа), фонтын 4 хэмжээ, зай, 2 товч.
- `tokens.css`: ижил утгууд CSS хувьсагчаар. 8-р хичээлд `styles.css`-ийн эхэнд тавина.

Figma-д оруулах: `style-guide.svg`-ийг canvas руу чирж тавина.
Солих: `#2457E0`-ийг өөрийн гол өнгөөр соль. Цагаан текст дээр contrast 4.5:1-ээс багагүй байх ёстой.
Фонт: Inter (Google Fonts, Cyrillic Extended). Өөр фонт сонговол ө, ү үсгийг шалга.
