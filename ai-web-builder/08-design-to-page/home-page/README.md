# Нүүр хуудас (8-р хичээлийн үр дүн)

- `index.html`: header, hero, үйлчилгээ ба үнэ, байршил, захиалгын хэсэг (одоохондоо утасны товч), footer.
- `styles.css`: style guide-ын хувьсагчууд (`:root`), mobile first, 768px ба 1024px дээр 2, 3 багана.
- `script.js`: footer-ийн оныг шинэчилнэ.

Нээх: `index.html` дээр давхар дар, эсвэл VS Code-оос **Reveal in Finder / Reveal in File Explorer**.
Харьцуулах: AI-ийн хийсэн хуудастайгаа зэрэгцүүлж хар. Хуулах албагүй.
Солих: нэр, хаяг, утас, үнийг өөрийн `content.md`-ээс соль. `tel:` холбоосны дугаарыг ч соль.
