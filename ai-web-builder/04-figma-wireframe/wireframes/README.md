# Wireframe-ийн жишээ (SVG)

- `home-mobile.svg` (390 өргөн), `booking-mobile.svg`, `confirmation-mobile.svg`: утасны 3 дэлгэц.
- `home-desktop.svg` (1440 өргөн): компьютерийн нүүр хуудас.

Figma-д оруулах: файлыг Figma-гийн canvas руу чирж тавина (drag and drop). SVG засах боломжтой vector layer болно.
Layer бүр нэртэй: Header, Hero, Services, Location, Booking form, Footer.
Солих: текстийг өөрийн агуулгын брифээр соль. Хэрэгтэй бол Frame дотор хийж Auto layout (Shift + A) нэм.
Өөрийн wireframe-ээ зурсан бол энэ файлыг зөвхөн харьцуулахад ашигла.
