# Claude Code-ийн тохиргоо

- `CLAUDE.md`: төслийн байнгын дүрэм. Claude Code session бүрийн эхэнд уншина.
- `prompts/01-plan-home.txt`: нүүр хуудасны төлөвлөгөө гаргуулах даалгавар (5 хэсэгтэй).
- `prompts/02-hero-only.txt`: зөвхөн эхний хэсгийг хийлгэх.
- `prompts/03-html-check.txt`: HTML-ийн чанарын шалгалт.
- `prompts/04-feedback.txt`: тодорхой санал өгөх жишээ (9-р хичээл).

Хуулах: `CLAUDE.md` ба `prompts` хавтсыг `salon-site`-ийнхаа үндсэн хавтсанд хуул.
Солих: CLAUDE.md-ийн бизнесийн нэр, өнгө, файлын нэрийг өөрийнхөөрөө соль.
Prompt-ыг Claude Code-д хуулж paste хийнэ. Нууц түлхүүр хэзээ ч бүү бич.
