# Алдаа олох дасгал

Энэ хуудсанд зориуд 3 алдаа нуусан. DevTools-оор нэг нэгээр нь ол.

1. `index.html`-ийг browser-т нээ. Загвар (CSS) огт алга. **Console**-ийг нээ (Mac: Cmd + Option + J, Windows: Ctrl + Shift + J).
2. Улаан мөр бүрийг хуулж Claude Code-д өг: шалтгааныг энгийнээр тайлбарлаад зас.
3. CSS засагдсаны дараа **Toggle device toolbar**-аар 375px өргөнд хар. Нэг хэсэг дэлгэцээс хальж байна.

Хариу (эхлээд өөрөө ол):
- `style.css` 404: файлын нэр `styles.css`.
- `Cannot set properties of null`: `script.js`-д `yaer` гэж буруу бичсэн, `year` байх ёстой.
- Хэвтээ scroll: `styles.css`-ийн `.cards` 2 баганатай, 260px тогтмол өргөнтэй. Утсан дээр `1fr` байх ёстой.
