# Эхлэлийн repo

- `index.html`, `styles.css`: 1-р хичээлийн анхны хуудас.
- `gitignore`: нууц файлыг Git-ээс хасах жагсаалт.
- `git-commands.txt`: хамгийн хэрэгтэй Git тушаалууд.

Нээх: хавтсыг `salon-site` гэж нэрлээд VS Code-оор нээ (**File > Open Folder**).
Zip-д цэгтэй файл ордоггүй тул `gitignore`-ийг `.gitignore` болгож нэрийг нь соль.
Дараа нь `git init`, `git add .`, `git commit -m "Initial commit"` хийгээд **Publish to GitHub**-аар нийтэл.
