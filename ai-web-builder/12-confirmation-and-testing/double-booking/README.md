# Баталгаажуулалт ба давхар захиалгын хамгаалалт (12-р хичээл)

- `apps-script/Code.gs`: `LockService`-ээр түгжиж, ижил өдөр ба цагтай захиалга байвал `slot_taken` буцаана. `taken` үйлдэл нь өдрийн захиалагдсан цагуудыг өгнө.
- `api/booking.js`: `slot_taken`-ийг 409 статустай монгол мессеж болгоно. `GET /api/booking?date=...` захиалагдсан цагуудыг өгнө.
- `script.js`: захиалагдсан цагийг сонголтод идэвхгүй харуулж, амжилттай бол баталгаажуулах хэсгийг гаргана.
- `TESTING.md`: 8 туршилтын хүснэгт.

Шинэчлэх: Code.gs-ийг Apps Script-д дахин paste хийгээд **Deploy > Manage deployments > Edit**, **Version: New version**, **Deploy**. URL өөрчлөгдөхгүй.
Нууц, хүснэгт 11-р хичээлийнхтэй ижил. `gitignore`-ийг `.gitignore` болгож нэрийг нь соль.
