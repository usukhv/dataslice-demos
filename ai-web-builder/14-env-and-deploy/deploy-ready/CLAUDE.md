# Цэцэг салон: цаг захиалгын сайт

## Төсөл
- Энгийн HTML, CSS, JavaScript. Framework, build, npm package ашиглахгүй.
- Файлууд: index.html, styles.css, script.js. Сервер код api/ (Vercel Functions), туслах код lib/.
- Захиалга Google Sheets-д хадгалагдана: apps-script/Code.gs.

## Дүрэм
- UI текст бүгд монгол кирилл. Тоо латин цифрээр.
- Mobile first: эхлээд 375px, дараа нь 768px, 1024px.
- Өнгө, зай зөвхөн styles.css-ийн :root хувьсагчаас. Шинэ өнгө нэмэхгүй.
- Сэтгэгдэл, тоо, шагнал зэрэг баталгаагүй мэдээлэл бүү зохио.
- Нууц түлхүүрийг зөвхөн process.env-ээс унш. Кодонд, prompt-д, README-д утгыг нь бичихгүй.
- Үнийг browser-оос авахгүй, зөвхөн lib/services.js-ээс.

## Ажлын дараалал
- Том өөрчлөлтөөс өмнө төлөвлөгөөгөө тайлбарлаад зөвшөөрөл хүлээ.
- Нэг удаад нэг хэсэг. Дуусмагц юуг яаж шалгахыг хэл.
