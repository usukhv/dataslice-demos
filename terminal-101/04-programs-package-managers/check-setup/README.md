# Суулгалтаа шалгах

- `check_setup.py`: git, python, brew, winget олдох эсэхийг шалгаж, хувилбарыг хэвлэнэ.
- `install-mac.txt`, `install-windows.txt`: хичээлийн суулгах командууд.

Ашиглах: Python суусны дараа тэр хавтсанд terminal нээгээд ажиллуул.
- Mac: `python3 check_setup.py`
- Windows: `python check_setup.py`
`not found` гэж гарсан программыг суулгаад terminal-аа хааж дахин нээ.
