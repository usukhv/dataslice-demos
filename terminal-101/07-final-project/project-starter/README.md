# hello-project

Терминал 101 курсийн төгсгөлийн төслийн бэлэн хувилбар.

- `hello.py`: `.env`-ээс `STUDENT_NAME`-ийг уншиж мэндэлдэг скрипт.
- `env.example`: нэрийг `.env.example` болгож соль. Хуулаад `.env` нэртэй файл үүсгэж, `STUDENT_NAME=` хойно нэрээ бич.
- `gitignore`: нэрийг `.gitignore` болгож соль. Zip-д цэгтэй файл ордоггүй тул ингэж өгсөн.

Ажиллуулах: zip-ийг задлаад тэр хавтсанд terminal нээ.

- Mac: `python3 hello.py`
- Windows: `python hello.py`

`.env`-ийг хэзээ ч commit хийж, хэнд ч илгээхгүй.
