# Хавтасны төөрдөг байшин

Дотор нь олон давхар хавтас бий. Хаа нэгтээ `treasure.txt` нуугдсан.

Ашиглах: zip-ийг Documents руу задал. Terminal-д `cd ~/Documents/folder-maze` гэж ор.
Зөвхөн `cd`, `ls` (эсвэл `dir`), `pwd`, `cd ..`-оор `treasure.txt`-ийг ол.
Олсон бол `pwd`-оор түүний absolute path-ийг бич. `My Projects` хавтас руу орохдоо хашилт хэрэглэ.
