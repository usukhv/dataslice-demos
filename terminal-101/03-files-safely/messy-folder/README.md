# Эмх замбараагүй хавтас

Хуучин файлууд холилдсон хавтас. Terminal-аар эмхэл.

Ашиглах: zip-ийг `terminal-practice` дотор задлаад `cd messy-folder`.
1. `photos`, `docs`, `old` хавтас үүсгэ (`mkdir`).
2. `photo-*.txt`-ийг `photos` руу, `report-*.txt`-ийг `docs` руу зөө (`mv`). Эхлээд `ls photo-*`-оор юу таарахыг хар.
3. `draft-*.txt`-ийг асуудаг хувилбараар устга: Mac `rm -i`, Windows `Remove-Item -Confirm`.
Бодит зураг биш, зөвхөн текст файл тул алдсан ч хохиролгүй.
