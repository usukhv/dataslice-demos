# Portfolio эхлэл

- `index.html`: нэг хуудас portfolio. Нэр, танилцуулга, 3 төсөл, холбоосоо соль. Тайлбар мөрүүд (`<!-- -->`) хаана юу солихыг заана.
- `README-template.md`: repo-гийн README загвар. Агуулгыг нь `README.md` руугаа хуул.
- `gitignore`: zip-д цэгтэй файл ордоггүй тул нэрийг нь `.gitignore` болгож соль.

Ашиглах: `index.html`-ийг browser-оор нээж шалга. Дараа нь `username.github.io` repo-доо **Add file**, **Upload files**-аар эсвэл GitHub Desktop-оор нэм.
`username` гэсэн бүх газрыг өөрийн GitHub username-ээр соль. Утас, гэрийн хаяг бүү нэм: repo public.
