# GitHub Desktop дадлага

- `projects-section.md`: README-д нэмэх **Төслүүд** хэсэг.
- `images/sample-work.svg`: даалгаварт repo руу хуулах жишээ зураг. Дараа нь өөрийн ажлын зургаар соль.

Ашиглах: clone хийсэн `username.github.io` хавтсаа нээ. `images` хавтсыг тэр хавтас руу хуул.
`README.md`-д `projects-section.md`-ийн агуулгыг нэм. GitHub Desktop-д өөрчлөлтүүд гарна.
**Summary** бичээд **Commit to main**, дараа нь **Push origin** дар.
