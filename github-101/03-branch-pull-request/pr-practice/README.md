# Pull request дадлага

- `skills-section.md`: README-д нэмэх **Ур чадвар** хэсгийн бэлэн текст.
- `projects-section.md`: даалгаврын `add-projects` branch-д нэмэх **Төслүүд** хэсэг.
- `pull-request-description.md`: pull request-ийн тайлбарын загвар.

Ашиглах: `add-skills` branch үүсгээд `README.md`-ийн төгсгөлд `skills-section.md`-ийн агуулгыг буулга.
Pull request нээхдээ тайлбарт `pull-request-description.md`-ийг хуулж бөглө.
Ур чадвар, төслийн нэрсийг өөрийнхөөрөө соль.
