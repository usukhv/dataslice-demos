# Shop Bot хүснэгтийн загвар

- `products.csv`: бараа (code, name, price, sizes, in_stock, description)
- `faq.csv`: түгээмэл асуулт, хариулт
- `conversations.csv`: ярианы бүртгэл (4-р хичээл)
- `orders.csv`: захиалга (5-р хичээл)

Нээх: Google Sheets дээр `Shop Bot` файл үүсгэ. CSV бүрийг **File** > **Import** > **Upload** хийгээд **Insert new sheets** сонго.
Sheet-ийн нэрийг `Products`, `FAQ`, `Conversations`, `Orders` болго (workflow-ууд яг энэ нэрийг хайна).
Жишээ мөрүүдийг өөрийн бараа, хариултаар соль. Үнийг зөвхөн тоогоор бич.
